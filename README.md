Implementing and training a DeepQ-Network for the "Lunar Lander" environment in OpenAI gym.

Implementation from the paper: "Human-level control through deep reinforcement learning" 
(https://web.stanford.edu/class/psych209/Readings/MnihEtAlHassibis15NatureControlDeepRL.pdf)

Required packages: gym, numpy, pytorch, matplotlib

How to run: DQN is contained in dqn.py All other functions are contained within main.py. Run as "python main.py", this should generate 6 output charts, 2 charts for an initial run until convergence and a test run of 100 episodes after convergence, as well as 4 output charts testing the effects on different hyperparameters on model performance.
